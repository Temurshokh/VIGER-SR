# VIGER AI Lab

**Telegram-first. Python-only.**

VIGER is now an experimental Telegram AI lab with two separate experiments:

```text
                         VIGER AI
                            │
              ┌─────────────┴─────────────┐
              │                           │
          IMAGE SR                    TINY LM
              │                           │
      2× / 4× super-resolution      text generation
              │                           │
          Swin2SR                 GRU trained from scratch
              │                           │
              └─────────────┬─────────────┘
                            │
                         Telegram
```

## Run it

Install Python 3.10+ and run:

```bash
python run_bot.py
```

The launcher checks dependencies, offers to install `requirements.txt`, asks for the Telegram token once, stores it locally in `telegram/.bot_token`, and starts the bot.

There is **no Visual Studio step, no CMake build, no `.exe`, and no local model server** in the Telegram workflow.

## Telegram

```text
/start
/status
/voice on
/teach Hi => Hello!
/train
```

Send a photo and choose **AI 2×** or **AI 4×**. Send text and the TinyLM generates a response from learned neural weights.

## TinyLM

`python/viger_tiny_lm.py` is a deliberately small character-level GRU language model trained **from scratch**. It starts with `data/chat.txt`, stores learned weights in `artifacts/viger_tiny_lm.pt`, and can be retrained after adding examples with `/teach`.

Example training idea:

```text
/teach Hi => Hello!
/teach Hello => Hi!
/teach Ping => Pong!
/train
```

This is an educational model, not a large general-purpose assistant. The important part is that the response is generated by the trained neural network rather than selected from a hard-coded fallback.

## Image SR

For the fast image experiment, the Python bot uses pretrained Swin2SR models locally for 2× and 4× reconstruction. This gives us a real neural SR pipeline immediately while the separate VIGER SR model is developed and benchmarked.

Large outputs are capped at 3840×2160 before sending to Telegram.

## Project structure

```text
VIGER-SR/
├── run_bot.py                 one-command launcher
├── telegram/bot.py            Telegram interface
├── python/sr_engine.py        image SR inference
├── python/viger_tiny_lm.py    self-trained TinyLM
├── data/chat.txt              TinyLM training corpus
├── artifacts/                 local model checkpoints
└── requirements.txt           Python dependencies
```

The old native/CMake implementation is kept in the repository history, but the active Telegram application does not depend on it.
